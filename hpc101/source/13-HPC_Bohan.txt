Inference: low-bit quantization
Low-bit Quantization Background

    Neural network quantization maps high-precision weights and activations to low-bit representations--such as
    INT8/INT4 or FP8/FP4--reducing memory footprint and bandwidth while enabling matrix multiplications to run
    efficiently on low-precision integer or floating-point hardware.

                                                                                                          Lower Power Consumption
                                                                                                                Lower Storage

                                                                                                               Lower Latency
                                                                                                            Lower Communication

                                                                                                                    Bandwidth
Quantization Formats: Binary/Ternary vs. Integer vs. Floating-Point

    Binary (1-bit): a single scale  × the sign

    Fixed-point INT-b: uniform grid -- zero-point-free (symmetric) vs. zero-point (asymmetric)

    Floating-point FP4 (NVFP4, E2M1): logarithmic grid + two-level scaling

    1 bit keeps only the sign; INT spreads its 2 levels uniformly (the zero-point z shifts the grid); FP spreads them logarithmically --
    dense near zero, where values cluster.

       [1] Rastegari et al., XNOR-Net, ECCV 2016. [2] Jacob et al., Quantization and Training of Neural Networks for Efficient Integer-Arithmetic-Only Inference, CVPR 2018. [3] NVIDIA, Pretraining Large Language
       Models with NVFP4, 2025.

Inference: Efficient Decoding
Speculative Decoding

                                                                                                                                                              Input: prefix x, draft model q, target model p, lookahead K
                                                                                                                                                              while not EOS:

                                                                                                                                                                 # 1. Draft K tokens sequentially
                                                                                                                                                                 y1...yK ~ q(. | x)
                                                                                                                                                                 # 2. Target scores all drafted positions in parallel
                                                                                                                                                                 compute p(. | x, y<1), ..., p(. | x, y<K)
                                                                                                                                                                 # 3. Accept / reject
                                                                                                                                                                 for i = 1 ... K:

                                                                                                                                                                     = min(1, p(yi) / q(yi))
                                                                                                                                                                    if Uniform(0,1)  :

                                                                                                                                                                       append yi to x
                                                                                                                                                                    else:

                                                                                                                                                                       sample z ~ normalize(max(p - q, 0))
                                                                                                                                                                       append z to x
                                                                                                                                                                       break
                                                                                                                                                                 # 4. If all K tokens accepted, sample one extra target token
                                                                                                                                                                 if all accepted:
                                                                                                                                                                    sample z ~ p(. | x, y1...yK)
                                                                                                                                                                    append z to x

Motivation: a target model can score all positions of the drafted sequence in parallel (prefilling), although the draft itself
may be sequential (decoding). Correct acceptance and recovery preserve the target model's output distribution.

Limitation:

· Autoregressive decoding emits one token per step; decode is often memory-bandwidth bound.

· The target model requires a separate LLM.

   Observation: (b) AR leads to memory-bound decoding. (c) Speculative decoding yields a variable number of
   accepted tokens that breaks regular batching. (d) MDLM predicts masked positions in parallel from per-position
   marginals, rather than their joint distribution.

   block of future tokens, modeling their joint distribution.
