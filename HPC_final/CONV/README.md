# 鲲鹏高性能计算全球挑战赛（S2 赛季）CONV 优化赛题

## 文件说明

- `conv2d.c`：优化后的二维卷积实现。
- `bench_conv.c`：官方基准与校验程序，保持原样，不要修改。
- `run_benchmark.sh`：编译并运行四个官方测试用例。
- `final_results.txt`：在鲲鹏 920 节点上的正式测试结果和基线对比。

## 编译

在鲲鹏集群上执行：

```sh
gcc -O3 bench_conv.c conv2d.c -o conv2d_test -lm -fopenmp
```

## 运行

```sh
bash run_benchmark.sh
```

也可以单独运行某一个测试：

```sh
OMP_NUM_THREADS=38 numactl -N 1 ./conv2d_test 4096 6144 39 39 1
```

参数依次为：输入行数、输入列数、卷积核行数、卷积核列数、测试重复次数。
官方容差为 `1e-5`，运行结果中的校验必须显示 `PASS`。

## 优化思路

1. 输出矩阵按行分配给 OpenMP 线程，避免线程之间写同一输出元素。
2. 在输出列方向使用 ARM NEON 处理 4 个 `float`，四个相邻输出行共享输入行读取；每个 8 列小块使用 8 个向量累加器，兼顾数据复用和寄存器压力。
3. 每个输出向量仍按“卷积核行 → 卷积核列”的顺序累加，并使用与鲲鹏上参考程序一致的融合乘加，避免改变浮点舍入结果。
4. 对高度不能整除四行的情况保留两行和单行收尾路径；直接把最终和写回输出，不再先清零输出数组。

非 ARM 机器保留了标量回退路径，便于做接口和正确性检查；正式性能数据应以鲲鹏 920F 集群为准。
